CLSS PWPush Extension - User Guide

📌 Overview

The **CLSS PWPush Extension** allows you to generate secure, self-destructing links for text or passwords. You can use it via the popup window or the right-click context menu.

⚡ Features

  • Send text or selected content to PWPush
  • Generate an encrypted, self-destructing link
  • Copy links directly to clipboard
  • Customize expiration time and security settings
  • Right-click menu integration

📥 Installation

You can install the extension directly from the Chrome Web Store:

👉 Install from Chrome Web Store

Manual Installation:

  1. Download and extract the extension files.
  2. Open chrome://extensions/ in your browser.
  3. Enable Developer Mode (top right corner).
  4. Click "Load unpacked" and select the extension folder.

⚙️ Configuration

To configure the extension, open the settings panel:

  1. Click on the **extension icon** in Chrome.
  2. Go to "Settings" and adjust parameters like expiration time and max views.
  3. Save your preferences.

🛠️ How to Use

Method 1: Using the Extension Popup

  1. Click on the extension icon.
  2. Enter text or a URL into the input box.
  3. (Optional) Adjust security settings.
  4. Click **"Generate PWPush Link"** – the link will be copied automatically.

Method 2: Using the Right-Click Context Menu

  1. Select any text on a webpage.
  2. Right-click and choose **"Send to PWPush"**.
  3. The generated link is copied to your clipboard.

🔒 Permissions Required

  • storage: Save settings.
  • contextMenus: Add the "Send to PWPush" right-click option.
  • activeTab: Execute scripts on the current tab.
  • scripting: Interact with the clipboard.
  • notifications: Display notifications after generating links.
  • clipboardWrite: Copy generated links automatically.
